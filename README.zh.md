## ⚽ 关于游戏

**国家队：足球经理**（*«Сборная: Футбольный Менеджер»*）是一款延续经典风格的国家队经理游戏。你可以执教 210 支国家队中的任意一支：征召球员、制定战术，在逐分钟模拟的比赛引擎中指挥比赛，带领祖国征战预选赛、欧国联、洲际锦标赛和世界杯。国际比赛日之间，还有 FIFA 排名、抽签、足协财务、球场建设、赛事申办以及来自世界各地的新闻。

游戏可直接在手机或电脑浏览器中运行，无需注册，首次加载后无需联网。同时提供 Windows 和 Android 版本。

> ℹ️ 所有球员、教练和俱乐部名称均为虚构并随机生成，如有雷同，纯属巧合。

## ✨ 游戏特色

### 🌍 足球世界
- 来自 6 大洲足联的 210 支国家队，Elo 等级分与星级实力评分
- 采用 SUM 公式的 FIFA 排名：每月更新、升降幅榜、可追溯至 1993 年的历史
- 全部赛事：48 队世界杯、欧洲杯、美洲杯、非洲杯、亚洲杯、金杯赛、欧足联与中北美洲国家联赛、附加赛、奥运会、青年世界杯与欧青赛
- 世界上每一场比赛都由同一引擎模拟——积分榜、对阵图和射手榜实时更新

### 🎲 抽签与赛事
- 根据 FIFA 排名分档的动画抽签
- 所有洲际赛事均遵循同洲回避规则
- 赛事申办、投票、联合主办与世界杯轮换制

### ⚽ 比赛与战术
- 逐分钟比赛引擎：控球、射门、xG、红黄牌、VAR、天气、补时
- 2D 球场、比赛势头图、文字解说、暂停与 ×4 倍速
- 场上换人与临场战术调整，加时赛与点球大战，球员评分
- 阵型、团队与个人指令，拖放式排兵布阵

### 👥 你的阵容
- 征召 18–23 名球员：7 项能力、状态、士气、潜力与性格
- 按位置线或单个球员安排训练，支持自动模式，可组织集训
- U-21 国青队、青训学院、双重国籍与归化
- 新闻发布会、球员谈话、足协信任度——以及下课

### 💰 足协与经济
- 赞助、转播、门票、奖金与周边收入对比各项开支
- 在不同城市新建和扩建球场
- 球衣赞助合同与主客场球衣设计器
- 可议价出场费的友谊赛

### 📊 数据与新闻
- 带 xG 的射门分布图、热力图、球员雷达对比
- 世界数据：射手榜、纪录、连胜/连败、球队实力
- 每个比赛窗口后的世界赛果汇总、俱乐部新闻、名人堂

### 🎨 贴心设计
- 20 种界面语言，支持从右到左（希伯来语、阿拉伯语、波斯语）
- 5 套主题：球场之夜、经典草坪、午夜蓝、浅色、沙色复古
- 20 个存档位 + 自动存档，可导出/导入，完全离线
- 可选作弊功能（存档会被标记）

## 🚀 如何游玩与安装

| | |
|---|---|
| 🌐 **浏览器** | 直接打开游戏页面即可——手机和电脑均可运行，还可以“添加到主屏幕” → [https://danyadanileckiy.github.io/national-football-manager/](https://danyadanileckiy.github.io/national-football-manager/) |
| 🪟 **Windows** | 下载便携版文件直接运行，无需安装： [`NationalFootballManager-Windows-portable.exe`](https://github.com/DanyaDanileckiy/national-football-manager/releases/latest/download/NationalFootballManager-Windows-portable.exe) |
| 🤖 **Android** | 下载并安装 APK： [`NationalFootballManager-Android.apk`](https://github.com/DanyaDanileckiy/national-football-manager/releases/latest/download/NationalFootballManager-Android.apk) |
| 💻 **本地运行** | 克隆仓库后打开 `index.html`，或运行 `python3 -m http.server` |

> ⚠️ **Windows SmartScreen:** 该文件未进行数字签名，Windows 可能提示“Windows 已保护你的电脑”。请点击 **“更多信息” → “仍要运行”**。
>
> ⚠️ **Android:** 安装 APK 时，请为浏览器或文件管理器开启 **“安装未知应用”** 权限（设置 → 安全）。

💾 存档保存在本机（IndexedDB）。如需在设备间转移生涯，请使用存档菜单中的导出与导入。

## 🛠️ 技术

- 纯 HTML、CSS 与 JavaScript——**无需构建、无框架、无依赖**
- 托管于 GitHub Pages 的静态网站，可完全离线运行
- 存档使用 IndexedDB 并经 gzip 压缩；赛程分批模拟，界面不会卡顿
- 国际化：20 种语言，国家名称来自 `Intl.DisplayNames`，翻译源文件位于 `i18n/src`
- Windows 版基于 Electron（便携版），Android 版基于 Capacitor（`packaging/`）
