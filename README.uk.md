## ⚽ Про гру

**«Збірна: Футбольний Менеджер»** (*«Сборная: Футбольный Менеджер»*) — менеджер національної збірної в дусі класики жанру. Ви стаєте головним тренером будь-якої з 210 збірних, викликаєте гравців, обираєте тактику, проводите матчі в похвилинному рушії та ведете країну крізь відбори, Ліги націй, континентальні чемпіонати й чемпіонат світу. Між вікнами — рейтинг ФІФА, жеребкування, економіка федерації, стадіони, заявки на проведення турнірів і новини з усього світу.

Гра працює просто в браузері на телефоні й комп'ютері, без реєстрації та без інтернету після першого завантаження. Є версії для Windows і Android.

> ℹ️ Усі імена гравців, тренерів і клубів вигадані та згенеровані. Збіги з реальними людьми випадкові.

## ✨ Можливості

### 🌍 Світ футболу
- 210 збірних із 6 конфедерацій, Ело та зірковий рейтинг сили
- Рейтинг ФІФА за формулою SUM: щомісячні знімки, рух, лідери зростання й падіння, історія з 1993 року
- Усі турніри: ЧС на 48 команд, Євро, Копа Америка, Кубки Африки й Азії, Золотий кубок, Ліги націй УЄФА та КОНКАКАФ, стикові матчі, Олімпіада, молодіжні ЧС і ЧЄ
- Усі матчі світу симулюються тим самим рушієм — живі таблиці, сітки та бомбардири

### 🎲 Жеребкування й турніри
- Анімовані жеребкування з кошиками за рейтингом ФІФА
- Правило конфедерацій в усіх міжконтинентальних турнірах
- Заявки на проведення турнірів, голосування, співорганізатори та ротація ЧС

### ⚽ Матч і тактика
- Похвилинний рушій: володіння, удари, xG, картки, VAR, погода, додатковий час
- 2D-поле, графік моментуму, коментарі, пауза та швидкість ×4
- Заміни й тактика під час гри, додатковий час і серії пенальті, оцінки гравців
- Схеми, командні та індивідуальні установки, склад перетягуванням

### 👥 Команда
- Виклик 18–23 гравців: 7 навичок, форма, мораль, потенціал, характер
- Тренування по лініях і гравцях з автоматичним режимом, тренувальні збори
- Молодіжна U-21, академія, подвійне громадянство та натуралізація
- Пресконференції, розмови з гравцями, довіра федерації та звільнення

### 💰 Федерація та економіка
- Спонсори, ТБ, квитки, призові та мерчендайз проти витрат
- Будівництво й розширення стадіонів у різних містах
- Технічний спонсор і дизайнер домашньої та гостьової форми
- Товариські матчі з переговорами про гонорар

### 📊 Статистика й новини
- Карти ударів з xG, теплові карти, радар порівняння гравців
- Світова статистика: бомбардири, рекорди, серії, сила команд
- «Світові підсумки» після кожного вікна, новини клубів, Зала слави

### 🎨 Зручність
- 20 мов інтерфейсу, зокрема RTL (іврит, арабська, фарсі)
- 5 тем: Нічний стадіон, Класичний газон, Опівнічний синій, Світла, Пісок/ретро
- 20 слотів збереження + автозбереження, експорт та імпорт, офлайн
- Необов'язкові чити (збереження позначається)

|---|---|

| 🪟 **Windows** | Завантажте портативний файл і запустіть — встановлення не потрібне: [`NationalFootballManager-8.0.0-portable.exe`](https://github.com/DanyaDanileckiy/national-football-manager/releases/download/v8.0/NationalFootballManager-8.0.0-portable.exe) |

| 💻 **Локально** | Клонуйте репозиторій і відкрийте `index.html` або запустіть `python3 -m http.server` |

> ⚠️ **Windows SmartScreen:** файл не підписаний, тому Windows може показати «Windows захистила ваш комп'ютер». Натисніть **«Докладніше» → «Однаково запустити»**.
>
> ⚠️ **Android:** для встановлення APK дозвольте **«Встановлення з невідомих джерел»** для браузера або файлового менеджера (Налаштування → Безпека).

💾 Збереження зберігаються локально на пристрої (IndexedDB). Щоб перенести кар'єру на інший пристрій, скористайтеся експортом та імпортом у меню збережень.

## 🛠️ Технології

- Чистий HTML, CSS і JavaScript — **без збирання, фреймворків і залежностей**
- Статичний сайт на GitHub Pages, повністю працює офлайн
- Збереження в IndexedDB зі стисненням gzip, симуляція невеликими порціями без зависання інтерфейсу
- i18n: 20 мов, назви країн через `Intl.DisplayNames`, вихідні файли перекладів у `i18n/src`
- Версія для Windows — Electron (portable), Android — Capacitor (`packaging/`)

## 🧪 Тести

```bash
node test/sim.js 8 FR     # симуляція двох циклів (~7000 матчів)
node test/fmt.js          # перевірка форматів турнірів
node test/draw.js         # перевірка жеребкувань
node test/i18n.js         # повнота перекладів
node test/qa20.js 20 FR 1 && node test/qa_report.js   # 20-сезонний QA і звіт
```
