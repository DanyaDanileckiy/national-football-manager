## ⚽ ゲームについて

**代表チーム：サッカーマネージャー**（*«Сборная: Футбольный Менеджер»*）は、ジャンルの名作の流れをくむ代表チーム監督ゲームです。210の代表チームから好きな国を選んで監督に就任し、選手を招集し、戦術を決め、1分ごとに展開する試合エンジンで采配を振るい、予選、ネーションズリーグ、大陸選手権、そしてワールドカップへと国を導きましょう。国際試合の合間には、FIFAランキング、組み合わせ抽選、協会の財政、スタジアム、大会招致、世界中のニュースが待っています。

スマホでもPCでもブラウザだけで動作し、登録は不要。初回読み込み後はオフラインでも遊べます。WindowsとAndroid向けのアプリもあります。

> ℹ️ 選手・監督・クラブの名前はすべて架空で、自動生成されたものです。実在の人物とは関係ありません。

## ✨ 主な機能

### 🌍 サッカーの世界
- 6つの大陸連盟に属する210の代表チーム、Eloレーティングと星による戦力評価
- SUM方式のFIFAランキング：毎月の更新、上昇・下降ランキング、1993年からの履歴
- すべての大会：48か国制ワールドカップ、EURO、コパ・アメリカ、アフリカ・ネイションズカップ、アジアカップ、ゴールドカップ、UEFA・CONCACAFネーションズリーグ、プレーオフ、オリンピック、ユース世代のW杯や欧州選手権
- 世界中の全試合を同じエンジンでシミュレート —— 順位表、トーナメント表、得点ランキングがリアルタイムで更新

### 🎲 抽選と大会
- FIFAランキングに基づくポット分けのアニメーション抽選
- すべての大陸間大会で同一連盟回避ルールを適用
- 大会招致、投票、共同開催、ワールドカップの持ち回り制

### ⚽ 試合と戦術
- 1分刻みの試合エンジン：ボール支配率、シュート、xG、カード、VAR、天候、アディショナルタイム
- 2Dピッチ、勢いグラフ、実況テキスト、一時停止と4倍速
- 試合中の交代と戦術変更、延長戦とPK戦、選手採点
- フォーメーション、チーム・個人への指示、ドラッグ＆ドロップでの先発編成

### 👥 チーム作り
- 18〜23人を招集：7つの能力値、調子、士気、ポテンシャル、性格
- ライン別・選手別のトレーニングと自動モード、強化合宿
- U-21代表、アカデミー、二重国籍と帰化
- 記者会見、選手との面談、協会からの信頼 —— そして解任

### 💰 協会と経済
- スポンサー、放映権、チケット、賞金、グッズ収入と各種支出
- さまざまな都市でのスタジアム建設・拡張
- サプライヤー契約とホーム／アウェイのユニフォームデザイナー
- 出場料を交渉できる親善試合

### 📊 データとニュース
- xG付きシュートマップ、ヒートマップ、選手比較レーダー
- 世界データ：得点ランキング、記録、連勝・連敗、チーム戦力
- 国際試合期間ごとの世界の結果ダイジェスト、クラブニュース、殿堂

### 🏆 キャリアとライバル
- 約60のダービーとノックアウトで生まれるライバル関係：直接対決、新聞の見出し、高まる重み
- 監督キャリア：評判、契約、就任オファー、辞任と新たな代表探し
- 44の実績と、目標・期限つきの12シナリオ；初心者向けヒント

### 🎨 快適さ
- 右から左への表示（ヘブライ語・アラビア語・ペルシア語）を含む20言語
- 5つのテーマ：スタジアムの夜、クラシックピッチ、ミッドナイトブルー、ライト、サンド／レトロ
- 20のセーブスロット＋オートセーブ、エクスポート／インポート、完全オフライン
- 任意のチート機能（セーブデータに印が付きます）

## 🚀 遊び方とインストール

| | |
|---|---|
| 🌐 **ブラウザ** | ゲームのページを開くだけ。スマホでもPCでも動作し、「ホーム画面に追加」もできます → [https://danyadanileckiy.github.io/national-football-manager/](https://danyadanileckiy.github.io/national-football-manager/) |
| 🪟 **Windows** | ポータブル版をダウンロードして起動するだけ（インストール不要）： [`NationalFootballManager-Windows-portable.exe`](https://github.com/DanyaDanileckiy/national-football-manager/releases/latest/download/NationalFootballManager-Windows-portable.exe) |
| 🤖 **Android** | APKをダウンロードしてインストール： [`NationalFootballManager-Android.apk`](https://github.com/DanyaDanileckiy/national-football-manager/releases/latest/download/NationalFootballManager-Android.apk) |
| 💻 **ローカル** | リポジトリをクローンして `index.html` を開くか、`python3 -m http.server` を実行 |

> ⚠️ **Windows SmartScreen:** ファイルにはコード署名がないため、「WindowsによってPCが保護されました」と表示される場合があります。**「詳細情報」→「実行」** をクリックしてください。
>
> ⚠️ **Android:** APKをインストールするには、ブラウザやファイルマネージャーに **「不明なアプリのインストール」** を許可してください（設定 → セキュリティ）。

💾 セーブデータは端末内（IndexedDB）に保存されます。別の端末へ移すときは、セーブメニューのエクスポート／インポートを使ってください。

## 🛠️ 技術

- 素のHTML・CSS・JavaScriptのみ —— **ビルド不要、フレームワークなし、依存関係なし**
- GitHub Pagesでホストされる静的サイトで、完全にオフライン動作
- セーブはgzip圧縮してIndexedDBに保存。日程は小分けにシミュレートするのでUIが固まりません
- i18n：20言語、国名は `Intl.DisplayNames` を利用、翻訳ソースは `i18n/src`
- Windows版はElectron（ポータブル）、Android版はCapacitor（`packaging/`）
