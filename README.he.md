## ⚽ על המשחק

**הנבחרת: מנג'ר כדורגל** (*«Сборная: Футбольный Менеджер»*) הוא משחק ניהול נבחרת לאומית ברוח הקלאסיקות של הז'אנר. קבלו לידיכם את אחת מ-210 הנבחרות, זמנו שחקנים, בחרו טקטיקה, נהלו משחקים במנוע דקה-אחר-דקה והובילו את המדינה דרך מוקדמות, ליגות האומות, אליפויות יבשתיות ומונדיאל. בין חלונות הנבחרות מחכים לכם דירוג פיפ"א, הגרלות, כספי ההתאחדות, אצטדיונים, הגשת מועמדות לאירוח טורנירים וחדשות מכל העולם.

המשחק רץ ישירות בדפדפן בטלפון ובמחשב — בלי הרשמה ובלי אינטרנט אחרי הטעינה הראשונה. יש גם גרסאות ל-Windows ולאנדרואיד.

> ℹ️ כל שמות השחקנים, המאמנים והמועדונים בדויים ונוצרו אוטומטית. כל דמיון לאנשים אמיתיים מקרי בהחלט.

## ✨ תכונות

### 🌍 עולם הכדורגל
- 210 נבחרות מ-6 קונפדרציות, דירוג Elo וכוח בכוכבים
- דירוג פיפ"א לפי נוסחת SUM: תמונות מצב חודשיות, עולות ויורדות, היסטוריה מאז 1993
- כל התחרויות: מונדיאל של 48 נבחרות, יורו, קופה אמריקה, אליפות אפריקה, גביע אסיה, גביע הזהב, ליגות האומות של אופ"א וקונקאקאף, פלייאוף, אולימפיאדה, מונדיאל ויורו לנוער
- כל משחק בעולם מדומה באותו מנוע — טבלאות, עצי טורניר ומלכי שערים בזמן אמת

### 🎲 הגרלות וטורנירים
- הגרלות מונפשות עם קדרות לפי דירוג פיפ"א
- כלל הקונפדרציות בכל הטורנירים הבין-יבשתיים
- מועמדות לאירוח, הצבעה, מארחות שותפות ורוטציית המונדיאל

### ⚽ משחק וטקטיקה
- מנוע דקה-אחר-דקה: החזקת כדור, בעיטות, xG, כרטיסים, VAR, מזג אוויר, תוספת זמן
- מגרש דו-ממדי, גרף מומנטום, פרשנות, השהיה ומהירות ×4
- חילופים וטקטיקה תוך כדי משחק, הארכה ודו-קרב פנדלים, ציוני שחקנים
- מערכים, הוראות קבוצתיות ואישיות, הרכב בגרירה

### 👥 הסגל שלכם
- זימון 18–23 שחקנים: 7 כישורים, כושר, מורל, פוטנציאל ואופי
- אימון לפי קו או לפי שחקן עם מצב אוטומטי, מחנות אימון
- נבחרת עד גיל 21, אקדמיה, אזרחות כפולה ואזרוח
- מסיבות עיתונאים, שיחות עם שחקנים, אמון ההתאחדות — ופיטורים

### 💰 התאחדות וכלכלה
- חסויות, טלוויזיה, כרטיסים, פרסים ומרצ'נדייז מול הוצאות
- בנייה והרחבה של אצטדיונים בערים שונות
- חוזה עם ספונסר ביגוד ומעצב תלבושות בית וחוץ
- משחקי ידידות עם משא ומתן על דמי השתתפות

### 📊 סטטיסטיקה וחדשות
- מפות בעיטות עם xG, מפות חום, מכ"ם השוואת שחקנים
- סטטיסטיקה עולמית: מלכי שערים, שיאים, רצפים, כוח הנבחרות
- סיכום תוצאות עולמי אחרי כל חלון, חדשות מועדונים, היכל התהילה

### 🏆 קריירה ויריבויות
- כ-60 דרבים ויריבויות שנולדות בנוקאאוט: ראש בראש, כותרות עיתונות, הימור גבוה יותר
- קריירת מאמן: מוניטין, חוזה, הצעות עבודה, התפטרות וחיפוש נבחרת חדשה
- 44 הישגים ו-12 תרחישים עם יעד ומועד; טיפים למתחילים

### 🎨 נוחות
- 20 שפות ממשק, כולל RTL (עברית, ערבית, פרסית)
- 5 ערכות נושא: לילה באצטדיון, דשא קלאסי, כחול חצות, בהיר, חול/רטרו
- 20 משבצות שמירה + שמירה אוטומטית, ייצוא וייבוא, עובד בלי אינטרנט
- צ'יטים אופציונליים (השמירה מסומנת)

💾 השמירות נשמרות מקומית במכשיר (IndexedDB). כדי להעביר קריירה למכשיר אחר, השתמשו בייצוא וייבוא בתפריט השמירות.

## 🛠️ טכנולוגיה

- HTML, CSS ו-JavaScript טהורים — **בלי שלב בנייה, בלי פריימוורקים ובלי תלויות**
- אתר סטטי ב-GitHub Pages שעובד במלואו גם בלי אינטרנט
- שמירות ב-IndexedDB עם דחיסת gzip; לוח המשחקים מדומה בחלקים קטנים כך שהממשק לא נתקע
- i18n: ‏20 שפות, שמות מדינות דרך `Intl.DisplayNames`, קובצי המקור של התרגומים ב-`i18n/src`
- גרסת Windows ב-Electron (ניידת), אנדרואיד ב-Capacitor (`packaging/`)

## 🧪 בדיקות

```bash
node test/sim.js 8 FR     # סימולציה של שני מחזורים (~7000 משחקים)
node test/fmt.js          # בדיקת מבני הטורנירים
node test/draw.js         # בדיקת ההגרלות
node test/i18n.js         # שלמות התרגומים
node test/qa20.js 20 FR 1 && node test/qa_report.js   # QA של 20 עונות ודוח
```
